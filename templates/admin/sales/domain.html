مراحل کار

  1. دامنه را در DNS به IP همین سرور وصل کنید (رکورد A).
  2. گواهی SSL را روی سرور بگیرید و مسیر فایل‌ها را بالا وارد کنید.
  3. فرم را ذخیره کنید.
  4. روی سرور vpnshop domain را اجرا کنید.

آن دستور تنظیمات Nginx را می‌سازد، دامنه را به فهرست مجاز اضافه می‌کند و سرویس پنل را ری‌استارت می‌کند. اگر تنظیمات معتبر نباشد، نسخه قبلی برگردانده می‌شود تا سایت از کار نیفتد.

گواهی ندارید؟ روی سرور: 

apt install certbot python3-certbot-nginx
certbot certonly --standalone -d YOUR_DOMAIN
