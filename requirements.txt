# Two supported stacks, picked automatically by pip from the running Python.
#
#   Python 3.10 / 3.11  ->  Django 5.1 + unfold 0.81   (Ubuntu 22.04 era servers)
#   Python 3.12 to 3.14 ->  Django 6.0 + unfold 0.102  (current servers)
#
# Django 5.1 does not support Python 3.14, and Django 6.0 requires 3.12, so no
# single pin covers both. unfold 0.81 is likewise the last release that runs on
# Python 3.10.
